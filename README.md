## 🎯 About the Bootcamp

This program is designed to accelerate development in core technologies demanded by the modern tech industry, combining the robustness of the **Java** ecosystem (with a strong focus on Object-Oriented Programming) with innovations in **Artificial Intelligence**, covering everything from Machine Learning fundamentals to next-generation language models (LLMs and SLMs).

---

## 🛠️ Technologies & Concepts Covered

### ☕ Object-Oriented Programming (OOP) & Java
* Java syntax and core language fundamentals.
* The 4 Pillars of OOP: Inheritance, Polymorphism, Encapsulation, and Abstraction.
* Creating classes, methods, constructors, and exception handling.
* Clean Code best practices.

### 🤖 Artificial Intelligence & Machine Learning
* **AI Fundamentals:** Introduction to core concepts and real-world applications.
* **Machine Learning:** Overview of supervised and unsupervised learning.
* **LLMs (Large Language Models) & SLMs (Small Language Models):** Understanding architectures, use cases, and application integration.
